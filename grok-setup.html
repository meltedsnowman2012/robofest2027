Grok 연결, 세 단계면 됩니다.

JUSTWEB 프로젝트에서 진행하세요. 비밀 키는 Supabase에만 저장합니다.

1. SQL 한 번 실행

  1. Supabase SQL Editor 열기 ↗
  2. 아래 버튼으로 SQL을 복사해서 새 쿼리에 붙여 넣습니다.
  3. 전체 코드를 선택 해제한 상태에서 Run을 누릅니다. “Grok 사용량 보호 설정 완료”가 나오면 성공입니다.
복사가 안 되면 코드 보기
기존 회원·채널·채팅은 유지됩니다. AI 사용 횟수 보호용 비공개 테이블과 함수를 추가합니다.


2. 서버 함수 만들기
  1. Supabase Edge Functions 열기 ↗
  2. Deploy a new function → Via Editor를 누릅니다.
  3. 함수 이름을 nextbot-grok으로 정합니다.
  4. 기존 예제 코드를 모두 지우고 아래 전체 코드를 붙여 넣은 뒤 Deploy function을 누릅니다.
  5. 함수 설정의 Verify JWT with legacy secret은 OFF로 설정합니다. 이 코드 안에서 로그인과 회원 권한을 직접 검증합니다.
함수 코드 보기


3. Grok 키 등록
  1. xAI 콘솔 열기 ↗ → API Keys에서 새 키를 만듭니다. API 사용에 필요한 크레딧과 지출 한도도 확인하세요.
  2. Supabase의 Edge Functions → Secrets로 이동합니다.
  3. Name에 XAI_API_KEY, Value에 만든 키를 넣고 저장합니다.
  4. NEXTBOT으로 돌아가기 ↗ → 로그인 → ✦ HYPER → Grok AI에서 질문합니다.
키를 채팅이나 GitHub에 올리지 마세요. 이 페이지에는 키를 입력하는 칸이 없습니다.
